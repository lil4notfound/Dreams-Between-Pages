# 纸上红楼

解压完整的 Windows 游戏包，保留 `纸上红楼.exe` 和 `chapters` 文件夹在同一目录，双击 `纸上红楼.exe` 启动。需要 Windows 10／11（64 位）和支持 Vulkan 的显卡及驱动。薄命司和十二章均可离线游玩。

## 游玩流程

1. **在薄命司找到警幻。** 你扮演贾宝玉。用 `W`、`A`、`S`、`D` 向前、左、后、右行走。走到警幻仙子面前按 `E` 交谈，继续按 `E` 或点击对话框，直到她动身引路。
2. **随警幻开柜。** 跟她走到题着「正册」的蓝金柜前。等她抬袖示意，靠近柜门按 `E`。柜中有十一册，林黛玉与薛宝钗共用一册。
3. **取册读判。** 点击柜中任意一册，书会在案上摊开。左页是判画，右页是判词。想换一册时，在书页上向左拖动看下一册，向右拖动看上一册。
4. **点判画，再点镜中人。** 点击左页判画，风月宝鉴会转向你。点击镜中人物，进入她的纸剧场。钗黛同册时，点黛玉进入黛玉章，点宝钗进入宝钗章。首次载入需要片刻。
5. **在书中探索正反两面。** 入镜后，宝玉也成了纸偶。按住宝玉拖动，或用 `WASD` 在书页上行走。点击人物或道具可触发各章的动作，例如在省亲殿点元春，她会起身，宝玉随之跪礼。按住空景左右拖动可转动整本书，转到背面，便能看见同一人物的另一幕。
6. **合册，继续读下一位。** 点击书脊或按 `Esc`，回到案上摊开的正册。可以左右拖动书页换册，再点判画入镜。想回薄命司走动，在读册时按 `Esc`。

## 打开工程

若分别下载了源码提交包和 Windows 完整版，将两个压缩包解压到同一目录，合并同名文件夹。用 Godot 4.7.2 导入 `project.godot` 可打开工程。薄命司和十二章的场景说明见工程内的 `docs` 文件夹。
